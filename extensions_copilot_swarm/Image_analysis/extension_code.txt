Here's the `main.js` code for your VS Code extension:

```javascript
import * as vscode from 'vscode';
import { analyzeImage } from './analyze-image';

export function activate(context: vscode.ExtensionContext) {
  context.subscriptions.push(
    vscode.commands.registerCommand('imageAnalysis.analyzeImage', async () => {
      const document = await vscode.window.activeTextEditor?.document;
      if (!document) {
        return;
      }

      try {
        await analyzeImage(document.getText());
        vscode.window.showInformationMessage('Image analysis completed successfully!');
      } catch (error) {
        vscode.window.showErrorMessage(`Error analyzing image: ${error.message}`);
      }
    })
  );
}

export function deactivate() {}
```

### Explanation:

1. **package.json**:
   - `name`: The name of the extension.
   - `version`: The version of the extension.
   - `description`: A brief description of the extension.
   - `engines.vscode`: Specifies the minimum VS Code version required by this extension.
   - `categories`: Specifies the category under which the extension will appear in the Extensions view.
   - `activationEvents`: Listens to activation events for the extension, such as opening text documents.
   - `contributes.commands`: Registers a command that can be invoked from the Command Palette.
   - `scripts`: Scripts to run before publishing (transpile TypeScript), start VS Code with development server, lint code, and test the extension.

2. **main.js**:
   - Import necessary modules from the VS Code API.
   - Define an activation function that registers a command to analyze images.
   - The `analyzeImage` function is assumed to be defined elsewhere in your extension (e.g., `./analyze-image.ts`) and takes the text of the active document as input.
   - Handle the execution of the command by reading the document, analyzing it using the `analyzeImage` function, and displaying a message based on the result.
