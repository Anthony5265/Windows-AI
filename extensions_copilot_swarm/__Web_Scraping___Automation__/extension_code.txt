### Main Code (index.js)

```javascript
import vscode from 'vscode';

export function activate(context) {
  const disposable = vscode.commands.registerCommand('webScrapingAutomation.runScrape', async () => {
    const editor = await vscode.window.showTextDocument();
    if (!editor) return;

    const text = editor.document.getText();
    // Perform your web scraping or automation here
    console.log('Scraped Text:', text);
  });

  context.subscriptions.push(disposable);
}

export function deactivate() {}
```

1. **Package.json**:
   - `name`: The name of the extension.
   - `version`: The version of the extension.
   - `engines.vscode`: Specifies that this extension is compatible with VSCode versions 1.42.0 and later.
   - `description`: A brief description of the extension.
   - `main`: The entry point for the extension, which is the JavaScript file containing the main functionality.
   - `scripts`:
     - `start`: Runs the code when the extension is started.
     - `build`: Compiles TypeScript code to JavaScript.
     - `watch`: Watches for changes in TypeScript files and compiles them on the fly.
     - `postinstall`: Builds the extension after it is installed.
   - `keywords`: Array of keywords for search results.
   - `author` and `contributors`: Information about the extension's author and contributors.
   - `license`: The license under which the extension is distributed.
   - `devDependencies`: Dependencies required during development.
   - `dependencies`: Dependencies required in production.

2. **Main Code (index.js)**:
   - Imports the `vscode` module.
   - Registers a command called `webScrapingAutomation.runScrape` that shows a text document and logs the scraped text to the console.
   - Adds the disposable to the subscriptions array, ensuring the command is active until it is explicitly disposed of.
