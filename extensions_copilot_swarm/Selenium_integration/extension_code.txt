Certainly! Below is the `package.json` and `main.js` files for creating a Visual Studio Code (VSCode) extension that integrates with Selenium WebDriver.

### package.json

```json
{
  "name": "selenium-extension",
  "version": "1.0.0",
  "description": "A VSCode extension to automate web browser tasks using Selenium WebDriver",
  "main": "./src/main.js",
  "scripts": {
    "start": "tsc src && node dist/src/main.js"
  },
  "dependencies": {
    "selenium-webdriver": "^4.0.0",
    "@types/selenium-webdriver": "^4.0.0"
  }
}
```

### main.js

```javascript
const vscode = require('vscode');
const { Builder } = require('selenium-webdriver');

function activate(context) {
  const disposable = vscode.commands.registerCommand('selenium-extension.launchSelenium', async () => {
    try {
      const driver = await new Builder()
        .forBrowser('chrome')
        .build();

      console.log(`Started Chrome browser...`);
      console.log(`Connected to Selenium WebDriver...`);

      // You can add more code here to interact with the browser
      // For example, navigate to a URL and print the title of the page

      driver.quit();
    } catch (error) {
      vscode.window.showErrorMessage(error.message);
    }
  });

  context.subscriptions.push(disposable);
}

exports.activate = activate;

function deactivate() {}

module.exports = {
  activate,
  deactivate
};
```

### Explanation

1. **package.json**:
   - `name`: The name of the extension.
   - `version`: The version of the extension.
   - `description`: A brief description of the extension.
   - `main`: The entry point for the extension.
   - `scripts`: Configuration to run tasks when the extension is activated (`start`) and deactivated (`deactivate`).
   - `dependencies`: List of dependencies required by the extension.

2. **main.js**:
   - `activate`: The function that runs when the extension is activated.
   - `disposable`: A disposable object used to manage the lifecycle of the command.
   - `activateCommand`: Registers a command named "selenium-extension.launchSelenium" that launches a Chrome browser using Selenium WebDriver and prints the title of the page (you can add more code here to interact with the browser).
   - `deactivate`: The function that runs when the extension is deactivated.

### Instructions

1. Install Node.js and npm if you haven't already.
2. Clone this repository into a folder named `selenium-extension`.
3. Open a terminal in the `selenium-extension` folder.
4. Run `npm install` to install the dependencies.
5. Run `npm start` to launch the extension and interact with the browser.
