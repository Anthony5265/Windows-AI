To create a VS Code extension that allows users to select the language for their documents and outputs the package.json and code in a specific format, you can follow these steps:

1. **Set up your VS Code extension project**:
   - Create a new folder for your extension.
   - Initialize a new npm project by running `npm init` in the terminal.
   - Choose a name and description for your extension.

2. **Configure your package.json**:
   - Open your `package.json` file and modify it to include the necessary information such as name, version, author, and main script.
   - Add the following dependencies if you need them:
     ```json
     "dependencies": {
       "vscode": "^1.64.0"
     }
     ```

3. **Create a new file for your extension**:
   - Create a new file named `extension.ts` in the root directory of your project.
   - Write the code to add commands and handlers for changing the language.

4. **Add a command to change the language**:
   - In your `extension.ts`, define a command that changes the language based on user input.

5. **Output package.json and code**:
   - Create a function in your extension that retrieves the package.json file, parses it, and formats it.
   - Also, create a function to generate some sample code for each supported language.
   - Call these functions from your command handler when the user selects the desired language.

Here's an example of how you might implement this:

```typescript
// extension.ts

import * as vscode from 'vscode';
import * as fs from 'fs';

function changeLanguage(document: vscode.TextDocument) {
  const language = document.languageId;
  // Add logic to change the language based on user input
  console.log(`Changing language to ${language}`);
}

function outputPackageJson() {
  const filePath = 'package.json';
  if (!fs.existsSync(filePath)) {
    vscode.window.showErrorMessage('File not found: package.json');
    return;
  }

  const content = fs.readFileSync(filePath, 'utf8');
  const parsedJSON = JSON.parse(content);

  // Output the package.json content in a specific format
  console.log('Package.json:');
  console.log(JSON.stringify(parsedJSON, null, 2));
}

function outputCode() {
  const filePath = 'src/index.js';
  if (!fs.existsSync(filePath)) {
    vscode.window.showErrorMessage('File not found: src/index.js');
    return;
  }

  // Generate sample code for each supported language
  const languages = ['javascript', 'typescript', 'python'];
  languages.forEach(language => {
    console.log(`Code in ${language}:`);
    const code = generateSampleCode(language);
    console.log(code);
  });
}

function generateSampleCode(language: string): string {
  switch (language) {
    case 'javascript':
      return `const message = 'Hello, world!';`;
    case 'typescript':
      return `let message = 'Hello, world!';`;
    case 'python':
      return `print("Hello, world!")`;
    default:
      return '';
  }
}

export function activate(context: vscode.ExtensionContext) {
  const disposableChangeLanguage = vscode.commands.registerCommand('extension.changeLanguage', () => changeLanguage(vscode.window.activeTextEditor?.document));
  context.subscriptions.push(disposableChangeLanguage);

  const disposableOutputPackageJson = vscode.commands.registerCommand('extension.outputPackageJson', outputPackageJson);
  context.subscriptions.push(disposableOutputPackageJson);

  const disposableOutputCode = vscode.commands.registerCommand('extension.outputCode', outputCode);
  context.subscriptions.push(disposableOutputCode);
}

export function deactivate() {}
```

6. **Create a `package.json` file**:
   - In the root directory of your project, create a new file named `package.json`.
   - Add the following information:
     ```json
     {
       "name": "language-selector-extension",
       "version": "1.0.0",
       "description": "A VS Code extension to change and output language-related files.",
       "main": "extension.js",
       "author": "Your Name",
       "license": "MIT",
       "devDependencies": {
         "vscode": "^1.64.0"
       }
     }
     ```

7. **Create a `README.md` file**:
   - In the root directory of your project, create a new file named `README.md`.
   - Add instructions for how to install and use your extension.

8. **Build and package your extension**:
   - Run `npm pack` in the terminal to create a tarball of your extension.
   - Install the extension by following the instructions provided in the `README.md`.

Now you have created a VS Code extension that allows users to change the language for their documents and outputs the package.json and code in a specific format. You can test this extension by running it in VS Code and using the provided commands.
