To create an VSCode extension that automates the process of running Narrator on your system for testing, you will need to follow these steps:

1. **Set up your project structure**:
   - Create a new folder for your VSCode extension.
   - Initialize a new Node.js project within this folder.

2. **Install necessary dependencies**:
   - You will need `electron` and `narrator-node-api` to interact with Narrator.
   - Add these as dependencies in your `package.json`.

3. **Write the extension code**:
   - Create a new file called `main.js` within your project folder.
   - Write the code that will trigger Narrator.

4. **Create a VSCode user interface** (optional):
   - You can create a simple UI for testing Narrator with buttons or inputs.

5. **Package and distribute your extension**:
   - Use tools like `electron-builder` to package your extension into a format compatible with VSCode.

Here is an example of what your `package.json` might look like:

```json
{
  "name": "narrator-automation",
  "version": "1.0.0",
  "description": "An extension for testing Narrator automation in VSCode",
  "main": "./src/main.js",
  "scripts": {
    "start": "node ./src/main.js",
    "build": "electron-builder -c ."
  },
  "author": "Your Name",
  "license": "MIT",
  "devDependencies": {
    "electron": "^17.0.2",
    "narrator-node-api": "^1.0.0",
    "electron-builder": "^23.4.2"
  }
}
```

Here is an example of what your `main.js` might look like:

```javascript
const { app, BrowserWindow } = require('electron');
const narrator = require('narrator-node-api');

function createWindow() {
  const win = new BrowserWindow({
    width: 800,
    height: 600,
    webPreferences: {
      nodeIntegration: true,
      contextIsolation: false
    }
  });

  win.loadFile('index.html');
}

app.whenReady().then(() => {
  createWindow();

  app.on('activate', function () {
    if (BrowserWindow.getAllWindows().length === 0) {
      createWindow();
    }
  });
});

// In case the application is closed by the operating system, this event will be emitted
process.on('exit', function () {
  narrator.stop();
});
```

To test Narrator using your extension, you can simply run `npm start` and navigate to `http://localhost:3000`. This will open a new browser window with your extension.

Finally, use `electron-builder` to package your extension into a format compatible with VSCode. This will create a `.vsix` file that you can install in VSCode.
