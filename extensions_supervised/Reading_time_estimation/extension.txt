 To create an VSCode extension that reads the estimated reading time of text files, you can follow these steps:

1. **Set up your VSCode extension project**:
   - Create a new directory for your extension.
   - Initialize a new Node.js project using `npm init`.
   - Install the necessary dependencies: `vscode`, `fs`, and `path`.

2. **Create the package.json file**:
   - In the root of your project, create a `package.json` file with the following content:
     ```json
     {
       "name": "read-time-extension",
       "version": "1.0.0",
       "description": "A VSCode extension to estimate the reading time of text files.",
       "main": "src/extension.js",
       "scripts": {
         "start": "code --extensions-dir node_modules -c \"require('./src/run')\"",
         "watch": "nodemon src/run.js"
       },
       "devDependencies": {
         "vscode": "^1.69.0",
         "nodemon": "^2.0.18"
       }
     }
     ```

3. **Create the code directory**:
   - Inside the root of your project, create a `src` directory.
   - In the `src` directory, create an `extension.js` file and add the following code:

     ```javascript
     const vscode = require('vscode');
     const fs = require('fs');
     const path = require('path');

     function activate(context) {
       context.subscriptions.push(vscode.commands.registerCommand('readTimeExtension.estimateReadingTime', async () => {
         const editor = vscode.window.activeTextEditor;
         if (!editor || !editor.document.isUntitled) {
           return vscode.window.showErrorMessage('Please open a text file.');
         }

         const document = editor.document;
         const content = document.getText();
         const estimatedReadingTime = calculateEstimatedReadingTime(content);

         vscode.window.showInformationMessage(`Estimated reading time: ${estimatedReadingTime} minutes`);
       });
     }

     function calculateEstimatedReadingTime(content) {
       const wordCount = countWords(content);
       return (wordCount / 200).toFixed(1);
     }

     function countWords(text) {
       return text.replace(/\s+/g, ' ').split(' ').length;
     }

     exports.activate = activate;
     ```

4. **Create the run.js file**:
   - Inside the `src` directory, create a `run.js` file and add the following code:

     ```javascript
     const { activate } = require('./extension');

     function start() {
       let disposable;

       vscode.window.onDidChangeActiveTextEditor(() => {
         if (disposable) {
           disposable.dispose();
         }
         disposable = activate(vscode);
       });

       vscode.workspace.onDidOpenTextDocument((document) => {
         if (!document.isUntitled && document.languageId === 'plaintext') {
           let disposable;

           vscode.window.onDidChangeTextDocument(() => {
             if (disposable) {
               disposable.dispose();
             }
             disposable = activate(vscode);
           });
         }
       });

       // Start listening for changes after the extension is activated
       activate(vscode);
     }

     start();
     ```

5. **Create the README.md file**:
   - In the root of your project, create a `README.md` file with the following content:

     ```markdown
     # Read Time Extension

     This VSCode extension estimates the estimated reading time of text files.

     ## Installation

     1. Open Visual Studio Code.
     2. Press `Ctrl + Shift + X` to open the Extensions view.
     3. Search for "Read Time Extension" and click on the install button.

     ## Usage

     - Open a text file in VSCode.
     - Click on the command palette (`Ctrl + Shift + P`) and type `Read Time Extension: Estimate Reading Time`.

     The estimated reading time will be displayed in a notification.

     ## Contributions

     - Fork the repository on GitHub.
     - Create a new branch for your changes.
     - Make your changes, commit them, and push to the new branch.
     - Open a pull request with your changes.

     ## License

     This project is licensed under the MIT license. See the [LICENSE](LICENSE) file for details.
     ```

6. **Build and package the extension**:
   - Run `npm run build` to compile your code into a `.vsix` file.
   - Open VSCode settings (`Ctrl + ,`), navigate to `Extensions`, and click on the gear icon next to "Read Time Extension" to select your installed version.

Now you should be able to open text files in VSCode, and it will estimate the estimated reading time of the content.
