## Finding Documentation

All markdown files in this directory tree are indexed and searchable. Use your IDE's search feature or:

```bash
# Find documentation by keyword
grep -r "keyword" docs/

# List all documentation files
find docs/ -name "*.md"
```

## Contributing to Documentation

Documentation contributions are welcome! Please:
1. Place docs in the appropriate category
2. Use clear, descriptive filenames
3. Include this doc in the table of contents
4. Follow the existing formatting style
5. Test all code examples

See [Contributing Guidelines](../CONTRIBUTING.md) for more details.

## Documentation Standards

- Use GitHub-flavored Markdown
- Include code examples where appropriate
- Add diagrams for complex concepts
- Keep language clear and concise
- Update the changelog when making significant changes
