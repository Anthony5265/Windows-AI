# Windows AI — Documentation Home

Welcome to the Windows AI knowledge base. Explore the guides below to learn about features and workflows.

## Feature Overview
- Control Center – manage agents and system modules.
- Universal Search – find files, web content, and device data in one query.
- Automation Builder – design reusable workflows and scripts.
- Mesh Networking – link machines to share compute.
- Mobile Companion – keep the assistant with you on the go.
