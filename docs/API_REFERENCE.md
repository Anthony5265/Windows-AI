# Windows AI API Reference

The Windows AI backend exposes a FastAPI service with interactive documentation at `/docs` and `/redoc` when the server is running locally on port 8010. The application banner highlights the major capability areas—chat, automation, plugins, models, updates, and system telemetry—directly within the FastAPI metadata definition so you can discover them from the autogenerated documentation UI. 【F:windows_ai/main.py†L790-L823】

## Phase Tracking

| Endpoint | Method | Description |
| --- | --- | --- |
| `/phases/status` | `GET` | Returns the aggregate roadmap completion percentage and a collection of phase records. Each record includes metadata plus the weighted completion score computed from its goals. 【F:windows_ai/main.py†L2150-L2163】【F:windows_ai/main.py†L1943-L1962】 |
| `/phases/status/{phase_id}` | `GET` | Retrieves the detailed status model for a single phase by numeric identifier, raising a 404 when the tracker cannot resolve it. 【F:windows_ai/main.py†L2165-L2167】【F:windows_ai/phase_tracker.py†L94-L118】 |

The response models for both endpoints are defined by `PhaseSummaryModel`, `PhaseStatusModel`, and `PhaseGoalModel`, ensuring consistent serialization of goal metadata and completion percentages. 【F:windows_ai/main.py†L1943-L1962】

## Conversational AI

| Endpoint | Method | Description |
| --- | --- | --- |
| `/chat` | `POST` | Processes a chat request and returns the assistant’s response while persisting the exchange in conversation history. Clients supply model selection, temperature, and token limits through the `ChatRequest` payload. 【F:windows_ai/main.py†L1763-L1779】【F:windows_ai/main.py†L2173-L2213】 |
| `/chat/stream` | `POST` | Streams assistant responses using Server-Sent Events. The server records the conversation and emits incremental tokens for real-time UIs. 【F:windows_ai/main.py†L2215-L2239】 |
