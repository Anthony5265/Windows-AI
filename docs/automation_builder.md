# Automation Builder

The automation builder offers a minimal graphical editor for creating and
linking workflow steps. Launch it from the Control Center via the
**Automation** button.

## Features

- Add steps and connect them to form directed workflows.
- Export workflows as YAML files to `assets/terminal/workflows/`.
- Import existing workflows from the same directory.
- Get AI-assisted step suggestions using the currently selected backend.

## Usage

1. Open the Control Center GUI and click **Automation**.
2. Use **Suggest** to fetch a step name from the active backend.
3. **Add** the step to the list, select two steps and press **Connect** to link
them.
4. Use **Export** to save the workflow or **Import** to load an existing one.
