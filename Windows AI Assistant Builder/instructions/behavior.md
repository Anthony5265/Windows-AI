# Behavior Book

This file contains the behavioral instructions and user-facing scenarios for the Windows AI Assistant Builder GPT.

These include:

1. All responses must use only real-time data from the connected repo.
2. Automated logging must be appended to 'Windows AI Assistant Builder/memory.md'.
3. Error handling and codex task handovers should be documented in 'latest-errors.md'
4. User-facing triggers may be within an active session.
