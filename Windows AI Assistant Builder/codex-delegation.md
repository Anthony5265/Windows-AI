# Codex Delegation Rules

This file defines what tasks the assistant GPT should not perform and how to hand them over to Codex.

## Tasks that must be delegated to Codex:
- Refractoring or structural updates to any module or feature
- Auditing major build systems, compilers, or integrations
- Adding, updating, and retraining any AI model component or core
- Any repo- wide rearch and repo rearchitecture

- These should be converted to Codex tasks with full detail and clear comments created automatically by the assistant.
