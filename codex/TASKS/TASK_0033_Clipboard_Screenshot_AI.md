# Task 33: Clipboard & Screenshot AI

**Goal**: One‑key actions for clipboard/screen content.

**Scope**
- Shortcuts: Summarize clipboard, OCR rectangle, Extract tables to CSV
- Redaction rules applied; local processing (no cloud by default)
- Results copied to clipboard + toast

**Acceptance**
- OCR returns ≥95% accuracy on printed text test set
- CSV extraction from table images produces correct columns
