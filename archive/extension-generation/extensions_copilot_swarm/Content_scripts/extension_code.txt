Certainly! Below is the `package.json` file and the corresponding `main.js` code for creating a VS Code extension that adds content scripts to the webpage.

### package.json

```json
{
  "name": "vscode-content-scripts",
  "version": "1.0.0",
  "description": "Adds content scripts to the web page using VS Code extensions.",
  "main": "./src/background.js",
  "scripts": {
    "start": "vscode:extensionDevelopmentContainer"
  },
  "devDependencies": {
    "code-server": "^0.216.2"
  }
}
```

### main.js

```javascript
// Import necessary modules from VS Code
const { commands } = require('vscode');

// Function to activate the extension
function activate(context) {
  // Register a command that will open a new tab with the content script loaded
  context.subscriptions.push(
    commands.registerCommand('contentScripts.openContentScript', () => {
      const editor = vscode.window.activeTextEditor;
      if (!editor) {
        return;
      }

      const textDocument = editor.document;

      // Define the content of the tab body
      const tabBody = `<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Content Script</title>
</head>
<body>
  <h1>Hello from the Content Script!</h1>
  <script src="${textDocument.uri.fsPath}/content.js"></script>
</body>
</html>`;

      // Create a new tab
      vscode.window.showTextDocument(vscode.Uri.parse(`vs://file:///dev/null#${tabBody}`));
    })
  );
}

// Export the activate function to be used by VS Code
module.exports = {
  activate
};
```

### Explanation

1. **package.json**:
   - `name`: The name of the extension.
   - `version`: The version of the extension.
   - `description`: A brief description of the extension.
   - `main`: The entry point for the extension, which is `background.js`.
   - `scripts`: Scripts to run when starting the extension development container.
   - `devDependencies`: Dependencies required during development.

2. **main.js**:
   - Import the necessary modules from VS Code.
   - Define the `activate` function that will be called when the extension is activated.
   - Register a command `contentScripts.openContentScript` that opens a new tab with the content script loaded.
   - The content of the tab body includes an HTML document with a `<script>` tag pointing to the `content.js` file in the same directory.

This setup allows you to use VS Code extensions to run custom JavaScript code on web pages.
