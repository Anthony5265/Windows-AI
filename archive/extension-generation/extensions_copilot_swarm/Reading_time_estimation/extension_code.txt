### README.md

```markdown
# VSCode Reading Time Extension

This extension provides a quick way to estimate the reading time of text in Visual Studio Code.

## Installation

1. Install the [VSCode CLI](https://code.visualstudio.com/docs/editor/commander).
2. Clone this repository: `git clone https://github.com/yourusername/vscode-reading-time.git`.
3. Navigate to the cloned directory: `cd vscode-reading-time`.
4. Install dependencies: `npm install`.

## Usage

1. Open a `.txt` file in VSCode.
2. Click on the "Reading Time" icon in the sidebar or press `Ctrl + Shift + T` (Windows/Linux) or `Cmd + Shift + T` (Mac).
3. The estimated reading time will be displayed in the status bar.

## Contributing

1. Fork this repository.
2. Clone your fork: `git clone https://github.com/yourusername/vscode-reading-time.git`.
3. Navigate to the cloned directory: `cd vscode-reading-time`.
4. Install dependencies: `npm install`.
5. Run the development server: `npm run serve`.
```

### main.js

```javascript
// package.json should have a "main" field pointing to this file
const vscode = require('vscode');

function activate(context) {
  const disposable = vscode.commands.registerCommand(
    'extension.readingTime',
    async () => {
      const editor = await vscode.window.activeTextEditor;
      if (!editor) return;

      const documentText = editor.document.getText();
      const wordsPerMinute = 200; // You can adjust this value
      const readingTime = documentText.split(' ').length / wordsPerMinute;
      vscode.window.showInformationMessage(`Estimated reading time: ${readingTime.toFixed(2)} minutes`);
    }
  );

  context.subscriptions.push(disposable);
}

function deactivate() {}

module.exports = {
  activate,
  deactivate
};
```

This is a very basic example, and you can expand it with more features such as integrating with a dictionary for accurate word counts, or using a more sophisticated algorithm to estimate reading time.
