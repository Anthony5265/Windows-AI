And here's the `main.js` file:

```javascript
const vscode = require('vscode');

function activate(context) {
  const openBrowserCommand = vscode.commands.registerCommand(
    'browserExtensions.openBrowser',
    () => {
      let editor = vscode.window.activeTextEditor;
      if (editor && editor.document.languageId === 'html') {
        vscode.env.openExternal(vscode.Uri.parse('https://www.example.com'));
      } else {
        vscode.window.showInformationMessage('Please open an HTML file first.');
      }
    }
  );

  context.subscriptions.push(openBrowserCommand);
}

exports.activate = activate;

function deactivate() {}

module.exports = {
  activate,
  deactivate
};
```

### Explanation:

1. **package.json**:
   - **name**: The name of your extension.
   - **version**: The version of your extension.
   - **description**: A brief description of the extension.
   - **engines**: The required VS Code version.
   - **categories**: The category under which your extension will be displayed in the Extensions view.
   - **activationEvents**: Specifies when to activate the extension (in this case, when a file is opened).
   - **main**: The entry point of the extension. In this case, it's `src/extension.js`.
   - **contributes**:
     - **menus**: Adds an action item to the editor context menu for opening browser extensions.
   - **devDependencies**: Lists any development dependencies.

2. **main.js**:
   - **activate**: The function called when the extension is activated.
   - **openBrowserCommand**: Registers a command that opens the default browser with a specified URL.
   - **deactivate**: An optional function to perform cleanup when the extension is deactivated.

This setup allows you to easily manage browser extensions within VS Code. When you open an HTML file, clicking the "Open Browser" action will open the default browser to `https://www.example.com`.
