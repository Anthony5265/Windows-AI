 To create an VS Code extension for form auto-fill and outputting `package.json` and code, you can follow these steps:

1. **Set up your development environment**:
   - Install Node.js and npm.
   - Install Visual Studio Code (VS Code).

2. **Create a new VS Code extension project**:
   - Open VS Code.
   - Press `Ctrl+Shift+P` (Windows/Linux) or `Cmd+Shift+P` (Mac).
   - Type `ext install` and select "Open Folder with Extensions".
   - Choose an existing folder or create a new one for your extension.

3. **Set up the project**:
   - Create a `package.json` file in your project root.
   - Install necessary dependencies using npm. For this example, you might need `vscode-api`.

4. **Create the main code**:
   - Create a JavaScript file that will handle the form auto-fill functionality.

5. **Test the extension**:
   - Run your extension in VS Code by pressing `F1` and selecting "Developer: Reload Window".
   - Test the form auto-fill feature to ensure it works as expected.

```json
{
  "name": "vscode-form-auto-fill",
  "version": "0.0.1",
  "description": "Automatically fill forms in VS Code",
  "main": "src/index.js",
  "scripts": {
    "start": "tsc && node dist/main.js"
  },
  "dependencies": {
    "vscode-api": "^4.29.0"
  }
}
```

And an example of what the `index.js` might look like:

```javascript
const vscode = require('vscode');

function activate(context) {
  const subscription = vscode.workspace.onDidOpenTextDocument(doc => {
    if (doc.languageId === 'html' || doc.languageId === 'typescript') {
      checkForFormFill(doc);
    }
  });

  return {
    dispose: () => {
      subscription.dispose();
    }
  };
}

function deactivate() { }

async function checkForFormFill(document) {
  const regex = /<form[^>]*>(.*?)<\/form>/s;
  const match = regex.exec(document.getText());
  if (match && match[1]) {
    fillForms(match[1]);
  }
}

function fillForms(formHtml) {
  // Implement the logic to fill forms with random data
  console.log('Form filled:', formHtml);
}

module.exports.activate = activate;
module.exports.deactivate = deactivate;
```
