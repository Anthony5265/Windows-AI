Creating a VS Code extension to optimize performance involves several key steps. The main focus will be on outputting the `package.json` file and analyzing the current state of your project's code for potential optimizations. HereΓÇÖs a high-level overview of how you can achieve this:

1. **Set Up Your Extension Project**:
   - Initialize a new VS Code extension using the Yeoman generator.
   ```bash
   yo vscode
   ```
   Follow the prompts to create your extension.

2. **Create a New File for Outputting `package.json`**:
   - In your extension project directory, create a file named `packageOutput.js`.
   ```javascript
   // packageOutput.js
   const fs = require('fs');
   const path = require('path');

   module.exports.activate = function(context) {
       context.subscriptions.push(
           vscode.commands.registerCommand('extension.packageOutput', async () => {
               const workspaceFolder = vscode.workspace.rootUri.fsPath;
               const packageJsonPath = path.join(workspaceFolder, 'package.json');

               if (fs.existsSync(packageJsonPath)) {
                   const content = fs.readFileSync(packageJsonPath, 'utf8');
                   console.log(`Package JSON:\n${content}`);
               } else {
                   console.log('No package.json found.');
               }
           })
       );
   };
   ```

3. **Create a New File for Analyzing Code**:
   - In your extension project directory, create a file named `codeAnalyzer.js`.
   ```javascript
   // codeAnalyzer.js
   const vscode = require('vscode');
   const fs = require('fs');
   const path = require('path');

   module.exports.activate = function(context) {
       context.subscriptions.push(
           vscode.commands.registerCommand('extension.codeAnalysis', async () => {
               const workspaceFolder = vscode.workspace.rootUri.fsPath;
               const files = await vscode.workspace.findFiles("**/*.js");

               if (files.length > 0) {
                   for (const file of files) {
                       const filePath = file.fsPath;
                       const content = fs.readFileSync(filePath, 'utf8');
                       console.log(`File: ${filePath}`);
                       console.log(content);
                   }
               } else {
                   console.log('No JavaScript files found.');
               }
           })
       );
   };
   ```

4. **Update the `package.json`**:
   - Ensure your `package.json` file has a script to activate your extension.
   ```json
   // package.json
   "scripts": {
       "start": "vscode-language-server --extension-path .",
       "watch": "nodemon src",
       "build": "tsc"
   }
   ```

5. **Create the Visual Studio Code Extension**:
   - In your `src` directory, create a file named `extension.js`.
   ```javascript
   // extension.js
   const vscode = require('vscode');
   const packageOutput = require('./packageOutput');
   const codeAnalyzer = require('./codeAnalyzer');

   exports.activate = function(context) {
       context.subscriptions.push(
           packageOutput.activate(),
           codeAnalyzer.activate()
       );
   };
   ```

6. **Test Your Extension**:
   - Run your extension using the following command:
     ```bash
     npm start
     ```
   - Open a new VS Code instance and try the `extension.packageOutput` and `extension.codeAnalysis` commands.

### Explanation

- **packageOutput.js**: This file provides a VS Code command that logs the content of the `package.json` file to the console. It uses Node.js's `fs` module to read the file.
- **codeAnalyzer.js**: This file provides another VS Code command that lists all JavaScript files in the workspace and prints their contents to the console. It also uses Node.js's `fs` module for reading the files.
- **extension.js**: This file registers the `packageOutput` and `codeAnalyzer` commands with VS Code.

By following these steps, you can create a VS Code extension that outputs the `package.json` and analyzes the current state of your project's code.
