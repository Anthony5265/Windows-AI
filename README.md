# Windows AI

Windows AI brings a local-first AI assistant to the Windows desktop. It combines search, automation and cross-device coordination through a modular architecture.

## Features
- **Control Center** – manage agents, services and settings from one panel.
- **Universal Search** – search files, web results and device data in a unified interface.
- **Automation Builder** – compose multi-step workflows with drag-and-drop or YAML.
- **Mesh Networking** – connect multiple machines to share tasks and resources.
- **Mobile Companion** – continue conversations and actions from your phone.
- **Security and Privacy** – sandboxed runtimes and per-action permissions.
